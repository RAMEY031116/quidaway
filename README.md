# QuidAway Streamlit Prototype

A polished Streamlit dummy prototype for a budget travel decision-maker.

## Features

- Budget/travel vibe form
- Globe spinner animation
- Randomised destination match
- Match score
- Destination result card
- Cheaper/similar alternatives
- Placeholder affiliate buttons
- Placeholder AdSense block
- Future feature section

## Deploy on Streamlit Cloud

1. Upload `app.py` and `requirements.txt` to a GitHub repo.
2. Go to Streamlit Cloud.
3. Create a new app.
4. Select your repo.
5. Main file path: `app.py`.
6. Deploy.

## Local run

```bash
pip install -r requirements.txt
streamlit run app.py
```
